# Datenbankprojekt – Buchtausch-App

## 1. Projektbeschreibung

Dieses Projekt implementiert eine relationale Datenbank zur Verwaltung
einer digitalen Bücherplattform.

Die Datenbank verwaltet unter anderem:

- Benutzer
- Bücher
- Autoren
- Verlage
- Sprachen
- Genres
- Leihanfragen
- Ausleihen
- Bewertungen
- Beschwerden

## 2. Voraussetzungen

Für die Ausführung wird ein MySQL- bzw. MariaDB-kompatibles
Datenbankmanagementsystem benötigt.

Empfohlen wird die Ausführung über eine geeignete Datenbankkonsole bzw. ein Datenbankverwaltungstool wie beispielsweise MySQL Workbench oder phpMyAdmin.

## 3. Installation

Die Installation bzw. Einrichtung der Datenbank erfolgt durch die einmalige Ausführung der mitgelieferten SQL-Datei.

### SQL-Datei

Denzer-Sebastian_UPS10823192_DLBDSPBDM01_D_ Abschlussphase_SQL.sql

### Verzeichnis

03_Finalisierungsphase

### Vorgehensweise

MySQL bzw. MariaDB starten.
Die oben genannte SQL-Datei in der Datenbankkonsole öffnen.
Das vollständige SQL-Skript ausführen.
Nach erfolgreicher Ausführung steht die Datenbank für die weitere Verwendung zur Verfügung.

### Nutzung

Nach der erfolgreichen Ausführung des SQL-Skripts kann auf die erstellte Datenbank zugegriffen werden.

Die im Projekt enthaltenen Tabellen, Beziehungen und Abfragen ermöglichen die Verwaltung und Auswertung der Daten der Bücherplattform.

Weitere Informationen zur Funktionalität und zu den verwendeten Datenbankobjekten sind im Abschlussdokument des Projekts beschrieben.
